# Shunno Dictionary (শূন্য ডিকশনারি)

**Shunno Dictionary** is a fast, lightweight, ad-free English dictionary and vocabulary reference for Android, featuring all **611,010 headwords and 828,447 senses** compressed into a modern SQLite and Zstd pipeline, styled with an **Apple iOS / macOS Cupertino UI** and a **transparent, zero-dim pop-up lookup mode** for e-readers and web browsers.
